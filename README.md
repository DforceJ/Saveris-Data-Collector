# Saveris-Data-Collector

# 🌡️ 코어빌드 온습도 데이터 자동 수집 시스템

이 저장소는 코어빌드 창고 및 생산 라인의 Testo Saveris 온습도 데이터를 매시간 자동으로 수집하여 저장하는 시스템입니다.

## ⚙️ 작동 방식
* **수집 주기:** 매 30 분마다 GitHub Actions 로봇이 자동으로 실행됩니다.
* **실행 스크립트:** `saveris_auto_collector.py` (파이썬)
* **결과 저장소:** `Saveris_Data.csv` 파일에 데이터가 누적됩니다.

## 📊 장비별 수집 조건 (필터링 로직)
* **A, B 장비 (회로창고):** 24시간 상시 수집
* **C, D, E, F, G 장비:** 근무 시간 (09:00 ~ 17:00) 데이터만 수집

## 🖥️ 대시보드 연동
이곳에 쌓인 CSV 파일은 Power BI의 [웹 데이터 가져오기]를 통해 대시보드와 실시간으로 연동되어 있습니다.
